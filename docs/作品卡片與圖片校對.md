# 作品卡片、圖片校對與連續問答（v2.0.0）

先完成 [學生安裝](部署指南.md)，再照本頁操作。這些功能已包含在 START_HERE.html 與單檔程式，不需要新增帳號或外部伺服器。

## 先更新原專案

依 [保留資料的升級指南](版本更新.md) 更新到 v2.0.0，包括新版 manifest、寄信授權、原部署更新及版本檢查。版本一致後同步一次，建立新首頁與主題；只改 Doc 時只需同步，不必重新部署。

## 首頁與 Quick Reply

輸入「首頁」「選單」「回首頁」可隨時開啟三張小型卡片：第一張姓名、肖像及聯繫本人，第二張幾句有履歷依據的特質，第三張主題導覽。

Quick Reply 固定保留 **我是誰、快速一覽**，其餘為同步產生的 **最多四個「類型：主題」特色**，一般共 3–6 項。類型依 Doc 內容選擇專案、技能、作品、經歷或證照，短名稱則指向具體項目，例如「專案：知識助理」「技能：報表自動化」「作品：網站介面」。同類型可有多項，沒有相關內容就不新增。基本資料用於介紹與概覽；適性特色的來源互斥分組，同件作品的文字與圖片歸入同組。概覽本來就涵蓋整份履歷，不宣稱它與各特色完全沒有內容交集。

- 公開內容未變時沿用同一份選單；成功同步新內容後才更新，不在每次聊天重新分類。
- 可區分的特色不足時可只顯示兩個基本入口，不為湊數編造專長。自然標題有助分組，但沒有固定履歷欄位要求。
- 點主題會開始該主題的查詢，不繼承先前作品範圍；一般「配色呢」等追問仍可沿用短期記憶。
- 「作品圖庫」「聯繫本人」「清除對話」「使用說明」「首頁」是操作指令，不占用適性特色項目。
- 在 GAS 執行 `testQuickReplyTopics` 或在校對頁按「測試主題問答」，可逐一核對主題答案與來源。這會用 Gemini 配額，但不發送 LINE 訊息、不把測試寫入待補充問題。

### 首頁肖像

把本人肖像插入公開區的「個人介紹」或「肖像」章節，再同步。程式會依章節與圖片內容辨識肖像，並準備供 LINE 顯示的獨立公開副本，原 Doc 與原圖仍保留原權限。沒有可用肖像時直接顯示幾何人物，不自動插圖到 Doc。不要把一般作品的人物插畫誤標為本人肖像。

若圖片辨識已更新但仍沒有頭像，核對 `checkDeployment`、同步結果 `portraitPreview` 及圖片是否曾由主人手動撤回預覽。明確手動撤回會被尊重，需在校對頁重新開放；不要只看本機預覽檔或 LINE 的舊訊息，請重新輸入「首頁」。

## 打開主人校對介面

1. 在 Google 文件的 `[[PUBLIC]]` 與 `[[/PUBLIC]]` 之間插入作品圖片，旁邊用自然標題標明作品名稱。先執行 `syncKnowledgeBase`。
2. 回到 GAS 左側檔案欄點「程式碼.gs／Code.gs」，從上方函式選單選 **`openImageReview`**，按「執行」。
3. 從下方「執行記錄」複製「主人管理介面」後的**完整連結，包含 `#` 後內容**，在新分頁開啟。
4. 介面會並排顯示原圖、「圖片文字」和「畫面描述」，可展開「查看 AI 原始辨識」。對照原圖修正後，按「儲存校對並同步」。確認綠色成功訊息，再回到 LINE 詢問。
5. 想撤銷校正可按「還原 AI 辨識並同步」。未儲存的文字可按「捨棄未儲存修改」。

這個連結有效 **20 分鐘**，持有者可管理圖片，請只供本人使用，不交作業、不轉傳學生群組。到期或按「結束管理」後，回到 GAS 重新執行 `openImageReview`。最多同時保留三個有效連結；新開過多連結會淘汰最舊的。只開 `/exec?view=review` 沒有完整的管理憑證，看不到履歷資料。

校對會另外存在自己的私有 Drive 管理 JSON，索引使用校對後文字；**不會將辨識或校對文字加進原 Google 文件**。原始辨識仍保留，換圖後不會把舊圖校正套到新圖。若只確認完全相同的辨識文字，不會為此重做向量。

頁面另有「檢查部署版本」，可核對目前執行版本與正式網址；若缺少 WEB_APP_URL，僅在 GAS 明確回傳目前正式 /exec 網址時補入，不改既有設定、不改寫 /dev。初次安裝仍依安裝說明手動填入自己的正式網址。

如果顯示「校對已保存，尚未同步成功」，表示校正有保存，但還不能用新內容回答。依錯誤訊息處理 API 額度、權限或文件更新後，再按「同步知識庫」，不要把它當成同步成功。

## 開放 LINE 作品圖文卡片

圖片可供 RAG 搜尋，不代表原圖已開放預覽。主人可逐張選擇：

1. 在校對頁找到要展示的作品。
2. 勾選同意將**這張作品的獨立副本**設為持連結者可讀，按「開放作品預覽」。
3. 等顯示「已開放」。程式會檢查副本網址能否匿名讀取、格式、檔案內容與預覽尺寸；原履歷、私有索引和校對管理檔維持私有。
4. 按「檢查 LINE 作品卡片」，確認 LINE 接受格式。這個檢查**不發送訊息**，也不能代替實際 LINE 顯示驗收。[LINE 訊息驗證介面](https://developers.line.biz/en/reference/messaging-api/#validate-reply-messages)
5. 自己到 LINE 輸入 **「作品圖庫」**，會收到作品圖文卡片（每次最多五張）。每張有作品名稱、辨識／校對描述、「問這件作品」與「查看原圖」。詢問圖片內容、且回答引用該圖時，也會附上已開放的作品卡片。

LINE 須能匿名讀取圖片，因此只公開選中的圖片副本，沒有公開整份文件。副本留在自己的 Drive；學校若禁止對外分享，會報錯，該圖仍可繼續用文字 RAG 問答，但無法展示公開卡片。Drive 預覽可用性亦受 Google 服務與政策影響。[Drive 分享介面](https://developers.google.com/apps-script/reference/drive/file#setSharing(Access,Permission))

按「撤回公開預覽」會停用新的卡片並將副本改回私有。刪圖、換圖或移出公開區後，下一次同步、校對載入或問答會檢查並撤回舊副本；這不是即時的 Drive 權限觸發器。**已傳送、下載或由 LINE 快取的圖片無法收回。**若報「分享撤回尚未完成」，按「重試撤回公開預覽」，必要時到自己的 Drive 將該副本改為私人。

## 短期對話記憶

LINE 一對一對話會暫存近期問題、目前作品指向及作品順序，約 **10 分鐘**：

1. 輸入「作品圖庫」。
2. 點海報的「問這件作品」，看回答與來源。
3. 再問「這張用了什麼配色？」「構圖呢？」；機器人會沿用所選作品，再從履歷索引取證據。
4. 看過多件作品時可問「第二件的配色呢？」；指向不明時會提供作品選擇卡片，不直接猜測。
5. 輸入 **「清除對話」**或「重新開始」立即清除。履歷公開內容更新後，舊的對話指向亦失效。

不同訪客分開記憶，以使用者識別碼的雜湊產生快取鍵，不保存訪客原始 LINE userId 或完整 AI 回答；主人另行設定的通知 userId 則存在指令碼屬性。追問仍要有當前履歷來源，不能把先前 AI 的回答當成事實。GAS 快取可能提早清除，若失去上下文，請補上作品名稱。[GAS 快取說明](https://developers.google.com/apps-script/reference/cache/cache)

## 學生驗收

| 測試 | 完成判斷 |
| --- | --- |
| 代表主題 | 固定兩項＋最多四個特色，特色無上下位或同義分類；不同回覆沿用同一份 |
| 同步更新 | 修改公開內容後同步，選單跟著更新；未改內容再次同步，選單保持相同 |
| 校對 | 修正圖中的一處錯字，LINE 回答使用校正結果；原 Doc 不新增文字 |
| 作品卡片 | 公開兩張不同用途作品，LINE 圖庫可見原圖與名稱；點圖可看副本 |
| 連續追問 | 選作品後問「配色呢」，答案及來源屬於同一作品 |
| 清除與隔離 | 清除對話後不沿用指向；另一位同學不會接到你的上一題 |
| 撤回 | 撤回預覽後，新圖庫沒有該圖；私人資料與管理檔從未公開 |
| 管理到期 | 失效連結看不到圖片與資料，重新執行管理函式可取得新連結 |

作業截圖請遮住金鑰、含 `?key=` 的 Webhook URL，以及圖片校對連結 `#` 後的管理憑證。

## 答案來源與聯繫入口

回覆可顯示「資料來源」文字，但不提供「展開答案依據」按鈕。歷史訊息上的舊按鈕只回覆停用。

第一張首頁的「聯繫本人」可開 Email 或留下邀約；「收到的邀約」與圖片校對共用主人管理頁。通知授權、userId 與實際驗收見 [聯繫與邀約通知](聯繫與邀約通知.md)。
