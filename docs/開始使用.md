# 安裝勾選清單

第一次操作搭配 [詳細安裝說明](部署指南.md)，履歷內容不熟悉時看 [填寫指南](履歷填寫指南.md)。

## 程式與自動履歷

- [ ] 下載最新安裝包並全部解壓縮，用瀏覽器開啟 START_HERE.html。
- [ ] 建立自己的 GAS 專案，貼入 [單檔程式](../dist/Code.gs)。
- [ ] 顯示 appsscript.json，貼入 [manifest](../gas/appsscript.json)。
- [ ] 儲存後，從左側「檔案」欄點回「程式碼.gs／Code.gs」。
- [ ] 在上方執行／偵錯附近的函式下拉選單選 `initializeProject`，按執行並完成授權。
- [ ] 從 `documentUrl` 打開含填寫指引及模擬履歷的文件。
- [ ] 確認 `RESUME_DOC_ID`、`DOC_TAB_IDS`、`WEBHOOK_TOKEN` 自動產生。

## API 與索引

- [ ] 建立自己的 LINE 官方帳號，啟用 Messaging API。
- [ ] 將 Channel access token 填入 `LINE_CHANNEL_ACCESS_TOKEN`。
- [ ] 將自己的 AI Studio Key 填入 `GEMINI_API_KEY`。
- [ ] 設定 `DISPLAY_NAME`。
- [ ] 執行 `testLineConnection`，status 為 ready、botName 為自己的帳號。
- [ ] 執行 `checkSetup`，credentials 三項為 true、document 為 ready。
- [ ] 執行 `syncKnowledgeBase`，再次檢查 index 為 ready。
- [ ] 執行 `testResumeAnswer`，對照原文件核對回答。

## 部署與 LINE

- [ ] 部署 Web App：以「我」執行、「所有人」可存取。
- [ ] 把正式 `/exec` 網址填入 `WEB_APP_URL`。
- [ ] 無痕視窗開啟 /exec，版本號與安裝包及 checkSetup.version 相同。
- [ ] 執行 `showWebhookUrl`，把含 key 的完整結果存到 LINE。
- [ ] Verify 成功、Use webhook 開啟，關閉重複自動回應。
- [ ] 加好友傳「選單」，收到首頁。
- [ ] 問已記載的問題，答案符合文件並有來源。
- [ ] 問未知問題，確認「待補充問題」新增記錄。

## 自己的履歷與維護

- [ ] 按填寫指南替換虛構資料，保留公開標記。
- [ ] 同步後重問，驗證更新。
- [ ] 需要時才執行 `installHourlySync`，不需要時用 `removeHourlySync`。
- [ ] 完成 [課堂驗收](課堂實作.md)，作業不附金鑰或含 key 的網址。
