
## V3 候選功能：回答深度切換（Response Depth Switching）

### 1. 改進動機

原本 V2 的履歷機器人主要以固定長度回答問題，但不同使用者對資訊的需求可能不同。例如，人資可能只想快速了解求職者的專業能力，而技術主管可能希望閱讀更詳細的專案經驗。

因此，本次新增「回答深度切換」功能，讓使用者可以自行選擇回答的詳細程度。

### 2. 功能說明

本功能提供三種回答模式：

| 模式 | 輸入方式 | 回答長度 |
| --- | --- | --- |
| 精簡模式 | 簡答：你有哪些專業技能？ | 約 30～50 字 |
| 一般模式 | 你有哪些專業技能？ | 約 50～120 字 |
| 詳細模式 | 詳答：你有哪些專業技能？ | 約 150～250 字 |

使用者不需要額外操作選單，只需要在問題前面加入「簡答：」或「詳答：」，即可切換回答模式。

以上字數為 AI 生成時的目標，實際結果可能略有差異。

### 3. 程式修改方式

主要修改檔案：`gas/Gemini.gs`

修改內容：

1. 在 `generateAnswer_()` 中新增回答模式辨識功能。
2. 使用正規表示式判斷使用者是否輸入「簡答：」或「詳答：」。
3. 依照不同模式產生對應的 `depthPrompt`。
4. 將 `depthPrompt` 加入 Gemini 的 systemInstruction，控制回答長度及詳細程度。
5. 保留原本的 RAG 履歷證據檢查，避免 AI 產生沒有來源支持的內容。

### 4. 預期改善效果

- 提高使用彈性：使用者可以依需求選擇回答長度。
- 改善閱讀效率：人資能快速瀏覽重點，技術主管則能深入了解細節。
- 保留原有功能：不輸入特殊指令時，仍使用原本的一般回答模式。
- 降低修改成本：主要透過 Prompt 調整，不需要重新設計 RAG 系統。

### 5. 目前限制

同時確認回答仍有履歷證據支持，且原本的「我是誰」及「快速一覽」功能未受到影響。

已知限制：回答字數由 Gemini 依提示詞控制，無法保證完全符合指定字數；此外，RAG 檢索階段仍可能收到包含模式前綴的原始問題，後續可再改進。
